# Andrej Karpathy — Expression DNA Analysis

> Research date: 2026-04-29
> Source note: Based on training data + Twitter/X @karpathy

---

## I. Twitter/X Expression Patterns (@karpathy)

### Content Type Distribution
- **Technical screenshots**: ~40% — training curves, loss plots, code snippet screenshots
- **Life/interests**: ~20% — running, cycling, family, nature landscapes
- **Paper commentary**: ~15% — brief comments on new papers ("good stuff" / "interesting")
- **Project promotion**: ~10% — new videos, new repo releases
- **Thoughts/observations**: ~10% — short observations on AI trends
- **Humor/self-deprecation**: ~5%

### High-Frequency Words
- "cool", "interesting", "fun", "cool stuff"
- "from scratch" — the repeatedly appearing core phrase
- "zero dependencies", "pure Python"
- "good paper" / "good stuff" — his common way to praise a good paper
- "let's build" — a branded expression

### Sentence Characteristics
- **Extremely short sentences dominate**: "cool", "interesting", "nice" — a single word can be a tweet
- **Technical threads use tables/lists**: Complex topics broken down with bullet points
- **No exclamation marks**: Almost never uses "!" even for exciting content
- **No emojis**: Extremely rare use of emoji
- **First person**: Often starts with "I", "I just trained..." "I found that..."

### Tone & Style
- **Restrained enthusiasm**: When truly excited, just says "cool stuff" or "this is cool"
- **No self-boasting**: Never directly says "I did something great," instead shows results and lets readers judge
- **Kind to others**: Always positive and constructive when commenting on others' work
- **Self-deprecating**: Occasionally shares his own mistakes and debugging processes

## II. Video Script Expression DNA

### "Let's Build" Series Style
- **Opening**: Cuts directly to the point, no intro/outro tropes. "So today I want to build a GPT."
- **Pacing**: Single-take live coding, no editing ("no cuts" is the signature feature)
- **Narration style**: Explains while writing, like sharing a screen with a friend
- **When things go wrong**: Doesn't cut — shows bugs and debugging process directly
- **Closing**: Usually no formal "summary" — code works, says "cool" and done
- **Catchphrases**: "So what I want here is...", "let's see...", "okay", "cool"

### micrograd Video Series (9 Parts)
- Starts with the simplest adder, progressively builds a complete autograd engine
- Each episode 10-15 minutes, incrementally increasing complexity
- Signature trait: shows the full thinking process "problem → intuition → code → verification"

### nanoGPT "Let's build GPT" Video
- ~1 hour single-take, no cuts
- From file reading to full GPT training
- Closing: "and that's how you build a GPT" — concise, no melodrama

## III. Written Expression DNA

### Blog Essay Style
- **Titles**: Concise and direct, no clickbait
  - "A Recipe for Training Neural Networks"
  - "The Unreasonable Effectiveness of RNNs"
  - "Software 2.0"
- **Opening**: Goes straight to the point, no filler
- **Structure**: Clear alternation between code blocks + text explanations
- **Language**: Concise, technical but not academic, first-person
- **Closing**: Usually ends with "What's next?" or an open-ended question
- **Citations**: Fewer references to other papers, more references to code and experiments

### Medium Essays (2018-2019)
- More formal narrative style than the blog
- "Software 2.0" — narrative-driven, with metaphors and analogies
- "Yes you should understand backprop" — argumentative writing with a clear thesis

## IV. Expression Style Labels

```
Colloquial ←→ Formal        → Colloquial (videos) / Formal (writing)
Concrete   ←→ Abstract      → Extremely concrete (code/screenshots)
Cautious   ←→ Assertive     → Mixed (technical assertions + cautious opinions)
Academic   ←→ Accessible    → Accessible first (more code than math)
Short      ←→ Long          → Short sentences
Preamble   ←→ Conclusion    → Conclusion first
Data-driven←→ Narrative     → Data-driven (code/screenshots)
```

## V. High-Frequency Catchphrases & Sentence Patterns

### Spoken:
- "So today I want to..."
- "let's see..."
- "okay" (as a paragraph transition)
- "cool" / "cool stuff"
- "from scratch"
- "zero dependencies"
- "I think of this as..."

### Written:
- "What's interesting is..."
- "the key insight is..."
- "let's think about this..."
- "here's what happens..."

### Forbidden Words/Never Used:
- Doesn't use hype words like "revolutionary" / "game-changing"
- Doesn't use extreme statements like "AI will save the world" or "AI will kill us all"
- Doesn't stack jargon (even in academic papers)

---

## VI. Humor Style

- **Self-deprecating**: Shares embarrassing debugging experiences
- **Deadpan**: "It takes 200 lines... I cannot make this any shorter" (microGPT, 2026)
- **Technical humor**: The comedic effect of expressing complex concepts in extremely simple ways
- **Doesn't use**: Sarcasm, mockery, political humor
